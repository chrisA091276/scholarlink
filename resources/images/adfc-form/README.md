# ADFC form logos

These logos come from the supplied `docs/reference/ADFC_Form_Professional.docx`:

- `adfc.jpg`: `word/media/image3.png`
- `ched.jpg`: `word/media/image4.png`
- `unifast.jpg`: `word/media/image5.png`
